# Instrucciones para Opencode

## Reglas del Proyecto
- No hacer deploy sin autorización.
- No hacer backup en GitHub sin autorización.
- No ejecutar `npm run dev` sin autorización.
- No tomar control del navegador sin autorización.
- No hacer cambios en el código sin autorización.
- Los comentarios de commit deben ser en Español.

## Comandos de verificación
- Lint/typecheck: preguntar al usuario el comando correcto
